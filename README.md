# 🔎 Tesseract Project

Transforme imagens em texto de forma simples e prática utilizando OCR (*Optical Character Recognition*).

## 🔥 Ideia

Após utilizar tecnologias de OCR em um projeto empresarial, decidi desenvolver uma aplicação própria para explorar o reconhecimento óptico de caracteres e suas possibilidades.

O objetivo é criar uma ferramenta capaz de extrair textos de imagens e documentos, permitindo visualizar, copiar e, futuramente, ouvir ou traduzir o conteúdo reconhecido.

O projeto também é uma oportunidade para aprofundar meus conhecimentos em JavaScript, processamento de imagens e integração de bibliotecas.

## ✨ Funcionalidades

- 🖼️ **Upload de imagens:** selecione uma imagem do seu dispositivo.
- 👁️ **Pré-visualização:** visualize a imagem antes de realizar o reconhecimento.
- 🔍 **Reconhecimento de texto:** extraia textos de imagens utilizando o Tesseract.js.
- 📋 **Copiar texto:** copie o conteúdo reconhecido para a área de transferência.
- 🔊 **Leitura em áudio:** funcionalidade planejada para converter o texto em fala.
- 🌎 **Tradução de idiomas:** funcionalidade futura para traduzir o texto reconhecido.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- [Tesseract.js](https://github.com/naptha/tesseract.js) — biblioteca JavaScript para reconhecimento óptico de caracteres (OCR).
